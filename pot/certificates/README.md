# Certificates

The portfolio now uses responsive certification cards instead of hard-coded PDF downloads. This avoids broken links while still making the section easy to maintain.

To add real certificate files later:

1. Place PDF or image files in this folder or in a shared `assets/certificates/` folder.
2. Add the credential link or local file path to the matching certification card in `index.html`.
3. Keep filenames simple, for example `databricks-data-engineering-fundamentals.pdf`.

- Databricks Data Engineering Fundamentals
- Databricks SQL Analytics
- IBM Data Engineering
- KPITB AI & Machine Learning
